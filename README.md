# Drieziek Watch

A responsive React + Vite prototype for a community safety incident feed.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Important prototype limitation
This version stores incident reports, photos, and messages in the browser's localStorage only. It does not broadcast updates to other residents or send alerts to security teams or emergency services. The map is a demonstration graphic, not a live map. Do not rely on this prototype for real emergency response.

## Vercel deployment
Framework: Vite
Build command: `npm run build`
Output directory: `dist`
